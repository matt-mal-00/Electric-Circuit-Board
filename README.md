# Papan Sirkuit Virtual

Simulator rangkaian listrik di browser (tanpa server dan tanpa library luar).

## Memasang ikon di perangkat
- **Laptop (Chrome atau Edge)**: buka alamat di atas, klik ikon pasang (monitor dengan panah) di ujung kanan kolom alamat, lalu **Install**. Ikon muncul di desktop atau menu Start.
- **Tablet atau HP Android (Chrome)**: menu titik tiga, lalu **Instal aplikasi** atau **Tambahkan ke layar utama**.
- **iPad atau iPhone (Safari)**: tombol Bagikan, lalu **Tambahkan ke Layar Utama**.

Setelah dibuka sekali, aplikasi bisa dipakai tanpa internet. Setelah mengunggah versi baru, ubah `V` di `sw.js` (misalnya `sirkuit-v2`) agar perangkat memuat versi terbaru.

# Virtual Circuit Board
An electrical circuit simulator that runs in the browser (no server and no external libraries).

## Installing the icon on your device
- **Laptop (Chrome or Edge)**: open the address above, click the install icon (a monitor with an arrow) at the right end of the address bar, then click **Install**. The icon appears on your desktop or Start menu.
- **Android tablet or phone (Chrome)**: open the three-dot menu, then choose **Install app** or **Add to Home screen**.
- **iPad or iPhone (Safari)**: tap the Share button, then **Add to Home Screen**.

Once opened for the first time, the app works offline. After uploading a new version, change `V` in `sw.js` (for example, `sirkuit-v2`) so that devices load the latest version.
